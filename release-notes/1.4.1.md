# Windows setup that finishes on slow machines

## Fixes

- **Windows: brand-new setup now runs in short steps instead of one long request.** Setup shows progress and lets you pause and resume, so slow PowerShell startup no longer makes the whole operation hit OpenChamber's 20-second request limit. Individual steps can still stop with recovery information if a helper is too slow or fails. The old single-request setup routes refuse on Windows; Linux and macOS keep them.
- **Progress: a sub-agent still recorded as Running now says "not seen in OpenChamber now" when it is absent from a complete session list.** This distinguishes the saved running state from what OpenChamber currently sees; it does not mark the work complete.

## Misc

- Release checks: reusable real-host test journeys help verify future releases. This is test-only work, with no change to product behavior.

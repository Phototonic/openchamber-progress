# Domain docs

This is a single-context repository. Before working in an area, read the relevant contracts in `docs/`, the root `GLOSSARY.md` if present, and relevant decisions in `docs/adr/` if present.

If the glossary or ADR directory does not exist, continue without scaffolding it. Create entries when a term or decision is settled.

Use glossary terms consistently in issues, proposals and tests. Flag conflicts with existing ADRs or contracts instead of overriding them silently.
